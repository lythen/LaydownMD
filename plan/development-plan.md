# Lythen-Markdown 开发计划

> 创建日期：2026-04-10
> 版本：v1.0

---

## 一、项目概述

**项目名称**：Lythen-Markdown
**项目类型**：桌面应用（跨平台 Markdown 编辑器）
**技术栈**：C# + Avalonia UI 11.2.0 + .NET 8.0
**目标平台**：Windows（首选）、macOS、Linux

---

## 四、开发顺序建议

```
第1周 → 项目搭建 → 文件管理 → 选项卡基础
第2周 → 选项卡完善 → 视图模式
第3周 → Markdown渲染 → 快捷键
第4周 → 帮助系统 → MVP 总结
     ↓
第5周 → 弹窗预览 → 主题切换
第6周 → 会话恢复 → 同步滚动
第7周 → 文件树 → 工具栏 → 查找替换
第8周 → 安装程序 → 阶段二总结
     ↓
第9周 → 在线更新
第10周 → 导出功能
第11周 → 最近文件 → 自定义快捷键
第12周 → 多语言支持 → 项目收尾
```
