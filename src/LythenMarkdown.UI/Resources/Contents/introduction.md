# Lythen-Markdown 软件介绍

## 关于 Lythen-Markdown

Lythen-Markdown 是一款简洁高效的 Markdown 编辑器，基于 Avalonia UI 跨平台框架开发，为用户提供流畅的编辑体验。

## 核心特性

### 编辑功能
- **实时预览**：编辑与预览同步显示，所见即所得
- **分栏模式**：左编辑、右预览，提高写作效率
- **多种视图**：支持纯编辑、分栏、纯预览三种模式切换
- **语法高亮**：支持 Markdown 语法高亮显示

### 文件管理
- **多标签编辑**：支持同时打开多个文件
- **会话恢复**：下次启动自动恢复上次工作状态
- **自动保存**：可选自动保存，防止意外丢失

### 扩展功能
- **主题切换**：支持浅色/深色主题
- **多语言支持**：简体中文、English
- **快捷键支持**：丰富的快捷键提升效率

## 技术架构

| 组件 | 技术 |
|------|------|
| UI 框架 | Avalonia 11.2.0 |
| 运行时 | .NET 8.0 |
| 编辑器 | AvaloniaEdit |
| Markdown 解析 | Markdig |
