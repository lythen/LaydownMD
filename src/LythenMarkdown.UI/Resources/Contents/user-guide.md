# Lythen-Markdown 使用说明

## 快速入门

### 新建文件
- 点击菜单 **文件 → 新建** 或使用快捷键 **Ctrl+N**

### 打开文件
- 点击菜单 **文件 → 打开** 或使用快捷键 **Ctrl+O**
- 支持 `.md` 和 `.markdown` 格式

### 保存文件
- 点击菜单 **文件 → 保存** 或使用快捷键 **Ctrl+S**
- 新文件首次保存会弹出另存为对话框

## 视图模式

Lythen-Markdown 提供三种视图模式：

| 模式 | 快捷键 | 说明 |
|------|--------|------|
| 编辑模式 | Ctrl+1 | 仅显示编辑器 |
| 分栏模式 | Ctrl+2 | 左编辑、右预览（默认） |
| 预览模式 | Ctrl+3 | 仅显示预览 |

## 常见问题

### 如何切换主题？
通过系统设置或右键菜单可以切换浅色/深色主题。

### 自动保存在哪里？
设置中可配置自动保存间隔，默认为 30 秒。

### 会话恢复需要手动操作吗？
不需要，下次启动软件会自动恢复上次的工作状态。
